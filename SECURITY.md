# Security policy

This is experimental camera software. Use the latest preview (0.3.2 or newer); older previews do not receive separate security backports.

Please report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/siavashHkh/a9-camera-macos/security/advisories/new). Include the affected version and steps to reproduce. Remove Wi-Fi passwords, camera frames, device identifiers, and personal network details from reports. Do not put credentials or private camera footage in public issues.

See [the security review](docs/SECURITY-REVIEW.md) for the review scope, mitigations, tests, and remaining protocol risks. A clean scanner result and passing tests do not guarantee that software is safe. The app is ad hoc signed and is not Apple notarized.
